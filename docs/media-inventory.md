## 14. Archive Notes

Some photographs intentionally appear in more than one logical category because the same physical view supports both a component-level and subsystem-level explanation. These duplicate repository paths are retained because the folder organization mirrors how the project was documented during development.

Original HEIC photographs and original high-resolution MOV recordings remain outside the GitHub repository. The repository contains the curated JPG/PNG evidence set and optimized H.264/MP4 recordings intended for review and portfolio use.
